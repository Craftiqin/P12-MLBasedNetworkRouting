# Simulation architecture

`simulator/core.py` builds a six-node graph with two source-gateway corridors and executes packets sequentially. Loss uses deterministic per-packet/link draws for paired algorithm comparisons. Latency and congestion are simplified parameters. `simulation/inet/` preserves the six-router AODV baseline. `simulation/inet/ml-routing/` adds a separate `MeshRoutingApp` C++ forwarder and INET ML scenarios; generated tree header is compiled into the app. AODV and ML use separate NED/INI projects and results. See [topology](../simulation/topology.md), [configurations](../simulation/configuration_guide.md), and [metric definitions](../simulation/metrics.md).
