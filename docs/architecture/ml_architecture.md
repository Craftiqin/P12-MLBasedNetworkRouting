# ML architecture

`ml/pipeline.py` generates synthetic link observations and trains a scikit-learn `DecisionTreeClassifier` with max depth 6, minimum leaf size 8 and balanced classes. Target: ACK success for one simulated link attempt. Features: RSSI, latency, estimated loss, throughput, remaining hops. `routing/engines.py` scores eligible next hops using predicted one-hop success and modeled shortest-tail success; it has loop avoidance, hysteresis and minimum-hop fallback. A separate INET path uses `simulation/inet/ml-routing/ml/route_policy.py` and exports a synthetic route-choice Decision Tree as a C++ header. `MeshRoutingApp` uses that prediction when selecting among two route corridors, after availability checks and safe fallback. No ESP32 firmware or measured observations exist. See [model integration boundary](../machine_learning/model_integration.md).
